# eResource Scheduler plugin for Cursor

Connect [Cursor](https://cursor.com) to [eResource Scheduler](https://www.eresourcescheduler.com) via MCP. OAuth is handled by Cursor.

## Setup

1. Install **eResource Scheduler** (Add from folder on the repo root).
2. Open **Settings → Tools & MCP** and confirm **eResource Scheduler mcp** is listed.
3. Click **Connect** (or type `mcp_auth` in chat if the browser does not open).
4. Sign in and approve the authorization request.

Default MCP URL:

```
https://test.eresourcescheduler.cloud/mcp
```
